 FELIGUINCHOS 🚗
 Plataforma Online de Serviços de Guincho

<sub>🚧 Projeto em desenvolvimento</sub>

 📌 Sobre o projeto

O FELIGUINCHOS é uma proposta de plataforma digital que tem como objetivo conectar pessoas que precisam de serviços de guincho a prestadores disponíveis, tornando o processo de solicitação e contratação mais simples e organizado.

O projeto está sendo desenvolvido como parte de uma iniciativa acadêmica, envolvendo planejamento de sistemas, estruturação de regras de negócio, análise de dados e tecnologias aplicadas à gestão.

 🎯 Objetivos

- Facilitar a solicitação de serviços de guincho.
- Aproximar clientes e prestadores.
- Organizar o gerenciamento dos atendimentos.
- Utilizar dados para acompanhar o desempenho da operação.
- Explorar possibilidades de Business Intelligence e Inteligência Artificial.

 📊 Análise de Dados e Business Intelligence

Uma das etapas desenvolvidas envolve a utilização do Power BI para demonstrar como os dados da plataforma poderiam auxiliar na tomada de decisões.

Foram criados indicadores e gráficos para acompanhar:

- Quantidade de solicitações.
- Serviços concluídos.
- Cancelamentos.
- Taxa de cancelamento.
- Faturamento.
- Comparação de resultados por região.

**Importante:** Os dados utilizados na demonstração são fictícios e possuem finalidade exclusivamente acadêmica. O painel ainda não está conectado a uma plataforma real.

 🤖 Inteligência Artificial

Também estão sendo estudadas possíveis aplicações futuras de IA, como:

- Previsão de demanda por região e horário.
- Recomendação de prestadores.
- Identificação de padrões de cancelamento.
- Estimativa do tempo de chegada dos prestadores.

Essas funcionalidades são propostas para etapas futuras e ainda não estão implementadas.

 🛠️ Tecnologias e ferramentas
- HTML e CSS — desenvolvimento de interfaces.
- Excel — organização de dados.
- Power BI — criação de indicadores e painéis.
- Inteligência Artificial — estudo de aplicações futuras.
